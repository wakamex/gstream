gstream is a small desktop app for watching Twitch: sign in once, see which of the channels you follow are live, and watch one in its window. It is a single executable for Linux and Windows, written in C on [gesso](https://github.com/wakamex/gesso), with no embedded browser.

The download is a 2.5 MB zip, and playing a 1080p60 channel on Windows 11 (Ryzen 7 3800XT, RTX 3080) takes 12% of one CPU core and 42 MB of memory.

## What it does

- Signs in with Twitch's device code: gstream shows a code, you enter it on Twitch's page in your own browser, and the session is kept for next time, encrypted for your user on Windows and in a file only your user can read on Linux.
- Lists the followed channels that are live, with thumbnails, viewer counts, titles and categories, refreshed in the background; search, sort, a mature-content toggle, and cards or compact rows.
- Plays the stream in the window or full screen, with mute, volume, and a diagnostics overlay (F1) showing the rendition, buffer, decoding path, dropped frames, CPU and memory.
- Chooses the quality automatically by default: it measures how fast video arrives and moves between the channel's renditions as the connection allows ("Auto 720p60" in the player bar). The quality menu fixes a rendition instead, down to audio only.
- Decodes video on the graphics card where the system offers it ([Video Acceleration API (VA-API)](https://github.com/intel/libva) on Linux, Direct3D 11 on Windows) and in software otherwise.
- Keeps playing through Twitch's ads and stream restarts, waits out network stalls, and fetches a fresh stream address when the old one expires.

`gstream --help` lists the command-line options, such as `--play CHANNEL` to start watching straight away.

## Downloads

- `gstream-v0.1.0-x86_64-linux.tar.gz`: Linux on x86-64 with glibc 2.27 or newer (Ubuntu 18.04 and later).
- `gstream-v0.1.0-x86_64-windows.zip`: Windows on x86-64.
- `gstream-v0.1.0-ffmpeg-source.tar.gz`: the source of the [FFmpeg](https://ffmpeg.org/) code linked into gstream, and the files used to build it, as FFmpeg's license (the GNU Lesser General Public License 2.1) asks.

Each archive holds the executable, the README, and the license texts of everything compiled in. To check that a download was built by this repository's release workflow, run `gh attestation verify ASSET --repo wakamex/gstream --signer-workflow wakamex/release-actions/.github/workflows/binary-release.yml`.

## Known limits

- No macOS download yet; macOS builds and passes its tests in CI.
- No chat, no low-latency mode, and no video on demand.
- On Fedora, Korean text in stream titles shows as boxes, because the system's only Korean font is in a format gstream cannot read yet.
